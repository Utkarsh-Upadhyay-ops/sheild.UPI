# UPI Shield clean source export

This package contains the complete available UPI Shield Vercel project: frontend, backend, source, bank icons/images, models, data, training scripts, tests, reports, and deployment config. It also contains the model lab notebook.

No production passwords, private keys, real `.env` file, or hosted service secrets are included. `.env.example` contains placeholders only. Local demo-only access/PIN values may appear in sample code and docs; these are not real payment credentials and must not be reused for production.

To run: install Node.js 24+, run `npm ci` then `npm run dev` and open http://localhost:4173. Set real service configuration separately using environment variables.
